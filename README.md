# جعبه‌ابزار دسترسی آزاد

ابزارهای عملی برای دسترسی به اینترنت آزاد در شرایط فیلترینگ شدید.

## شروع سریع

```bash
git clone https://github.com/uvghhc880-crypto/arena.git
cd arena
bash install.sh
```

بعد:
```bash
free-config --list      # لیست ۸۸+ کشور
```

## راهنمای کامل

**👉 [`README-START.md`](README-START.md)** را بخوانید — از صفر تا کار کردن.

## محتویات

| پوشه | کار |
|---|---|
| `iran-access/` | جمع‌آور کانفیگ رایگان، تفکیک‌شده بر اساس ۸۸+ کشور |
| `iran-tunnel/` | تانل ایران→خارج، چند تونل WireGuard موازی، تولید کانفیگ Clash |
| `warp/` | اسکن و عیب‌یابی endpoint های Cloudflare WARP |

## ابزارها

| دستور | کار |
|---|---|
| `free-config` | کانفیگ رایگان از ۸۸+ کشور با تست سرعت |
| `gen-links` | تولید لینک `vless://` برای هر کاربر × هر کشور |
| `gen-clash` | کانفیگ Clash با گروه انتخاب کشور (تجربه‌ی اپ‌های تجاری) |
| `wg-multipath` | چند تونل WireGuard موازی روی یک سرور |
| `warp-scan` | اسکن endpoint های WARP برای کشور خروجی دلخواه |

## وضعیت تست

| بخش | وضعیت |
|---|---|
| نصب خودکار | ✅ تست‌شده |
| پارس کانفیگ WireGuard (شامل خطاها) | ✅ تست‌شده |
| تولید لینک و کانفیگ | ✅ تست‌شده |
| اعتبارسنجی JSON کانفیگ‌های Xray | ✅ تست‌شده |
| اعتبارسنجی YAML کانفیگ Clash | ✅ تست‌شده |
| اسکن endpoint WARP | ✅ منطق تست‌شده |
| اجرای زنده روی سرور | ⏳ نیازمند سرور واقعی |

## هشدار امنیتی

کانفیگ‌های رایگان از منابع عمومی می‌آیند. اپراتور آن‌ها متادیتای ترافیک شما را می‌بیند.
**برای بانک، ایمیل و اطلاعات هویتی از آن‌ها استفاده نکنید** — از Psiphon / Lantern / nthLink / Tor استفاده کنید.
