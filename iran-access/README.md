# iran-access — دسترسی آزاد به اینترنت

راهنمای عملی برای دسترسی به اینترنت آزاد با **ابزارهای رایگان و قانونی** — بدون نیاز به پرداخت دلاری، بدون دور زدن اشتراک کسی.

---

## چرا این راه، نه اون راه؟

شما گفتید به **آی‌پی از کشورهای زیاد** نیاز دارید چون با ۳-۴ لوکیشن بعضی سایتا باز نمی‌شن.

خبر خوب: این نیاز **قبلاً حل شده**. یه اکوسیستم داوطلبانه‌ی بزرگ وجود داره که دقیقاً برای همین ساخته شده و:

| | دستکاری اپ‌های تجاری | اکوسیستم کانفیگ آزاد |
|---|---|---|
| تعداد لوکیشن | ۳-۴ تا (رایگان هر اپ) | **۸۸ کشور** |
| تعداد نود | محدود به پلن | **هزاران کانفیگ** |
| به‌روزرسانی | دستی، شکننده | **هر ۱۵ دقیقه خودکار** |
| دوام | با هر آپدیت می‌شکند | پایدار |
| هزینه | ۰ (ولی غیرقانونی) | **۰ (قانونی)** |
| اپدیت‌شدن | شما باید بجنگید | خودش انجام می‌شه |

شما خودتون اشاره کردید که Octohide «جدیداً این‌طور شده» — یعنی راه دور زدن، **راه فرسایشی** است. اما اکوسیستم بالا برای این کار ساخته شده.

---

## بخش ۱ — ابزارهای رسمی و امن (اول این‌ها رو امتحان کنید)

این‌ها **سازمان‌های غیرانتفاعی** هستن که با بودجه‌ی عمومی برای دور زدن فیلترینگ ساخته شدن. رایگان، بدون تبلیغ، و **مورد اعتماد**:

### 🔵 Psiphon
- **مهم‌ترین ابزار برای ایران** — در اوج محدودیت‌ها به **۹.۶ میلیون کاربر روزانه** در ایران رسید
- رایگان و بدون محدودیت حجم
- پروتکل‌های متنوع (SSH، obfs4، domain fronting)
- وب‌سایت: `psiphon.ca`

### 🟣 Lantern
- رایگان، متن‌باز، با **میلیون‌ها کاربر ایرانی**
- تکنیک **TLS record fragmentation** — SNI رو تکه می‌کنه تا از فیلتر رد شه
- **هزاران آی‌پی در روز می‌چرخونه** — یعنی وقتی یه محدوده بسته می‌شه، سریع برمی‌گرده
- حالت «Unbounded» برای کمک داوطلبانه
- وب‌سایت: `lantern.io`

### 🟢 nthLink
- ساخته‌شده مخصوص کشورهای با سانسور شدید
- رایگان، از OTF بودجه می‌گیره

### ⚫ Tor + Snowflake
- Snowflake از مرورگر اجرا می‌شه، بدون نصب چیزی
- مقاوم‌ترین ابزار در برابر سانسور پیشرفته
- وب‌سایت: `snowflake.torproject.org`

### 🟡 ProtonVPN / Windscribe (پلن رایگان)
- ProtonVPN رایگان: **بدون محدودیت حجم**
- Windscribe: ۱۰ گیگ در ماه
- سرورهای قانونی و پایدار

> 💡 **این‌ها چرا امن‌ترن؟** اپراتورشون مشخصه، متن‌بازن، و توسط بنیادهای غیرانتفاعی (Open Technology Fund) حمایت مالی می‌شن.

## بخش ۲ — ابزار `iran-access` (ساخته‌شده برای نیاز شما)

این ابزار کانفیگ‌های عمومی و داوطلبانه رو جمع می‌کنه، بر اساس کشور تفکیک می‌کنه، تست می‌کنه و مرتب می‌سازه.

### قابلیت‌ها
- ✅ **۸۸ کشور** — آلمان، هلند، آمریکا، فرانسه، انگلیس، ترکیه، امارات، ژاپن، ...
- ✅ ۴ منبع عمومی، با **۵ آینه** (برای وقتی گیت‌هاب مستقیم باز نمی‌شه)
- ✅ پشتیبانی از ۶ پروتکل: `vless`, `vmess`, `trojan`, `ss`, `hysteria2`, `tuic`
- ✅ حذف خودکار تکراری‌ها
- ✅ **تست اتصال TCP** و مرتب‌سازی بر اساس تأخیر واقعی
- ✅ خروجی برای همه کلاینت‌ها

### نصب

فقط پایتون ۳ لازمه (چیز دیگه‌ای نمی‌خواد):

```bash
python3 --version    # باید 3.7+ باشه
```

### استفاده

```bash
# 1) ببین چه کشورهایی موجوده
python3 iran-access.py --list

# 2) کانفیگ کشورهای مورد نظرت رو بگیر
python3 iran-access.py --countries DE,NL,US,FR,GB,TR -o sub.txt

# 3) با تست اتصال و مرتب‌سازی بر اساس سرعت (پیشنهادی)
python3 iran-access.py --countries DE,NL,US --test -n 50 -o fast.txt

# 4) همه‌ی ۸۸ کشور
python3 iran-access.py --all -o all.txt
```

**نمونه خروجی:**
```
    + Germany                  ->  1016
    + Netherlands              ->  584
    + USA                      ->  2400
    + France                   ->  428

[*] کل کانفیگ یکتا: 4314
[*] کانفیگ سالم: 884

[+] ذخیره شد:
    متن ساده : sub.txt   (4314 کانفیگ)
    base64   : sub_base64.txt
```

### گزینه‌ها

| گزینه | کار |
|---|---|
| `--list` | لیست کشورها |
| `--countries DE,NL` | انتخاب کشور (کد ISO) |
| `--all` | همه کشورها |
| `--mixed` | منابع ترکیبی همه‌پروتکلی |
| `--test` | تست اتصال + مرتب‌سازی بر اساس تأخیر |
| `-n 50` | فقط ۵۰ کانفیگ برتر |
| `-o out.txt` | نام فایل خروجی |
| `--workers 40` | تعداد رشته‌ی تست (کند‌شبکه: کمتر بدهید) |

## بخش ۳ — کلاینت‌ها (اپ‌ها)

فایل خروجی رو توی این کلاینت‌ها ایمپورت کنید:

| پلتفرم | کلاینت | توضیح |
|---|---|---|
| **اندروید** | [v2rayNG](https://github.com/2dust/v2rayNG) | محبوب‌ترین، ساده |
| **اندروید** | [Hiddify](https://github.com/hiddify/hiddify-next) | مدرن، همه‌کاره، **پیشنهاد من** |
| **اندروید** | [NekoBox](https://github.com/MatsuriDayo/NekoBoxForAndroid) | قدرتمند، پیشرفته |
| **ویندوز** | [Hiddify](https://github.com/hiddify/hiddify-next) / [v2rayN](https://github.com/2dust/v2rayN) | — |
| **مک** | [Streisand](https://streisand.app) / V2Box | — |
| **iOS** | Streisand / V2Box / Shadowrocket | — |
| **لینوکس** | Nekoray / sing-box | — |

**نحوه ایمپورت:**
1. فایل `sub.txt` یا `sub_base64.txt` رو به گوشی منتقل کنید
2. در کلاینت: `Subscription` → `Import from file` (یا `Add from clipboard`)
3. `Update subscription` بزنید
4. از منوی گروه‌بندی, بر اساس کشور انتخاب کنید

> 💡 **نکته:** خیلی از کلاینت‌ها می‌تونن لینک ساب‌اسکریپشن بدین به‌جای فایل. اگه ابزار رو با `--out` ذخیره کردید، می‌تونید فایل رو روی یه هاست بذارید و لینکش رو بدید. یا از خود لینک‌های گیت‌هاب مستقیم استفاده کنید.

### لینک‌های آماده (بدون ابزار)

اگه نمی‌خواید ابزار رو اجرا کنید، این لینک‌ها رو مستقیم در کلاینت اضافه کنید:

## بخش ۴ — ⚠️ هشدارهای امنیتی (مهم!)

### 🔴 کانفیگ‌های عمومی، امنیت کامل نمی‌دن

وقتی از کانفیگ کسی استفاده می‌کنید که نمی‌شناسیدش:

| ریسک | توضیح |
|---|---|
| **دیدن متادیتا** | اپراتور می‌فهمه به چه سایت‌هایی سر می‌زنید (حتی اگه محتوا رمزنگاری‌شده باشه) |
| **هانی‌پات** | ممکنه اپراتور خودش دولتی باشه |
| **لاگ‌گیری** | معلوم نیست چی ذخیره می‌کنه |
| **تزریق محتوا** | در سایت‌های HTTP (بدون S) می‌تونه محتوا دستکاری کنه |

### ✅ قوانین استفاده‌ی مطمئن

1. **برای کارهای حساس (بانک، ایمیل، هویت) از این کانفیگ‌ها استفاده نکنید**
   → برای این کارها **Psiphon / Lantern / nthLink / Tor** (بخش ۱) استفاده کنید

2. **همیشه HTTPS را چک کنید** — آیکون قفل در مرورگر

3. **کانفیگ‌های ناشناس رو برای ورود به حساب‌های شخصی استفاده نکنید**

4. **هر چند وقت عوض کنید** — بذارید ابزار دوباره اجرا شه

5. **دو لایه بذارید** — یعنی: ترافیک مهم → ابزار معتبر | ترافیک عادی → کانفیگ عمومی

### 🥇 بهترین راه: سرور خودتان

اگه یه VPS ارزون بگیرید (۳-۴ دلار ماهانه، بعضی جاها کمتر)، خودتون Xray نصب می‌کنید:
- 🔒 امنیت کامل — کسی به ترافیکتون دسترسی نداره
- ♾️ بدون محدودیت کاربر
- 🎯 آی‌پی ثابت و پایدار
- 👥 می‌تونید با چند نفر شریک بشید — یعنی هر نفر کمتر از ۱ دلار

اگه خواستید، اسکریپت نصب و راه‌اندازیش رو کامل براتون می‌نویسم.

## بخش ۵ — می‌خواید کمک کنید؟ (دقیقاً همون کاری که گفتید)

شما گفتید هدفتون **کمک به مردمه**. بهترین راهش اینه که نه مصرف‌کننده، بلکه **تأمین‌کننده** باشید:

### Psiphon Conduit
پهنای باند گوشی/کامپیوترتون رو برای کاربران تحت سانسور اهدا کنید:
```
اپ Psiphon → Settings → Conduit → Enable
```

### Snowflake (پروژه Tor)
از توی مرورگر، یه خط دفاعی برای کاربران سانسورشده بشید:
```
https://snowflake.torproject.org  →  "Run a Snowflake Proxy"
```

### Lantern Unbounded
همون مفهوم — کسیکه دسترسی داره، به کسیکه نداره پل می‌ده.

### یا: سرور خودتون رو عمومی کنید
اگه VPS دارید، کانفیگش رو در یکی از همون مخازن عمومی منتشر کنید تا بقیه استفاده کنن.

> 💡 **نکته:** هزینه‌ی حمایت از یک کاربر برای یک ماه در این بنیادها **حدود ۷ سنت** است. یعنی با پول یه قهوه، می‌شه دسترسی اینترنت برای ده‌ها نفر فراهم کرد.

## بخش ۶ — عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `هیچ کانفیگی به دست نیامد` | آینه رو عوض کنید یا VPN دیگه‌ای روشن کنید |
| خیلی از کانفیگ‌ها FAIL | نرمال — معمولاً ۷۰-۹۰٪ زنده‌ان. با `--test -n 30` برترین‌ها رو بردارید |
| تست خیلی کند است | `--workers` رو کم کنید (مثلاً ۱۵) |
| کانفیگ وصله ولی سایت باز نمی‌شه | کلاینت رو عوض کنید یا `--test` رو با `-n 20` اجرا کنید |
| `gh` نصب نیست | مشکلی نیست — ابزار خودکار به آینه‌ها برمی‌گرده |
| همه‌چیز FAIL شد | احتمالاً اینترنت شما خودش محدوده — اول با Psiphon وصل شید، بعد ابزار رو اجرا کنید |
