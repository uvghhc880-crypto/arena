# انتخاب کلاینت — کدام اپ برای معماری شما؟

شما الان **VLESS + REALITY** دارید با چند کشور. پس کلاینت باید این‌ها را پشتیبانی کند:
- ✅ VLESS + REALITY
- ✅ چند پروفایل / ساب‌اسکریپشن
- ✅ تست تأخیر (برای انتخاب کشور)

## 🔴 اول این را بخوانید — دام APK جعلی

این **مهم‌ترین نکته امنیتی** برای کاربران ایرانی است:

| اپ | وضعیت |
|---|---|
| **v2rayNG** | آپدیت: پلی‌استور `com.v2ray.ang` از سپتامبر ۲۰۲۶ خطای ۴۰۴ می‌دهد. **فقط از `github.com/2dust/v2rayNG`** |
| **NekoBox** | 🚨 لینک Play Store آن از **می ۲۰۲۴ توسط شخص ثالث تصاحب شده**. هرگز نسخه Play را نصب نکنید. فقط `github.com/MatsuriDayo/NekoBoxForAndroid` |
| **Hiddify** | ✅ روی Play Store و GitHub و F-Droid — امن‌ترین گزینه برای کاربر عادی |

> ⚠️ برای کاربران عادی که نمی‌توانید روی نصب‌شان نظارت کنید، **Hiddify** بهترین انتخاب است — چون از Play Store نصب می‌شود و نیازی به sideload کردن APK ندارد. APK‌هایی که در گروه‌های تلگرام دست‌به‌دست می‌شوند، یکی از رایج‌ترین راه‌های آلودگی گوشی در ایران هستند.

## ۱. Hiddify — پیشنهاد اول برای اکثر کاربران

**چرا:** تیم سازنده‌اش ایرانی است و برای همین شرایط ساخته شده. یک اپ برای اندروید، iOS، ویندوز، مک و لینوکس.

**نصب:** `app.hiddify.com` یا Play Store یا `github.com/hiddify/hiddify-app`

**افزودن کانفیگ شما:**
1. فایل `ali_base64.txt` را باز کنید و کل متن را کپی کنید
2. در Hiddify: `+` → `Add from clipboard`
3. تمام کانفیگ‌های کشورها اضافه می‌شوند
4. روی فلش «تست تأخیر» بزنید تا سریع‌ترین مشخص شود

**نکته:** اگر سرور ساب‌اسکریپشن دارید (فایل را روی یک URL گذاشته‌اید)، `Add from link` بزنید تا خودکار به‌روز شود.

## ۲. FlClash / ClashMetaForAndroid — تجربه‌ی Octohide

این‌ها با فایل YAML کار می‌کنند که `gen-clash.py` می‌سازد. نتیجه:

```
Proxies
  ├─ تست خودکار (سریع‌ترین)   ← خودش سریع‌ترین کشور را انتخاب می‌کند
  ├─ انتخاب کشور              ← شما دستی انتخاب می‌کنید
  │    ├─ 🇩🇪 آلمان
  │    ├─ 🇳🇱 هلند
  │    └─ 🇺🇸 آمریکا
  └─ DIRECT
```

**این نزدیک‌ترین چیز به تجربه‌ی اپی مثل Octohide است** — با این تفاوت که سرورها مال خودتان است و هرچند کشور که بخواهید می‌توانید اضافه کنید (Octohide رایگان فقط ۷ تا دارد).

**نصب:**
- اندروید: `github.com/chen08209/FlClash` یا `github.com/MetaCubeX/ClashMetaForAndroid`
- ویندوز/مک: `github.com/clash-verge-rev/clash-verge-rev` یا Mihomo Party
- iOS: Shadowrocket یا Stash

**افزودن:** `Profiles` → `New` → `Import from file` → فایل `ali-clash.yaml`

**ساخت کانفیگ Clash:**
```bash
python3 gen-clash.py --spec users.json --out ./out --user ali
```

## 🎯 برای کاربران غیرفنی چه کنید؟

اگر هدف کمک به افرادی است که با تکنولوژی راحت نیستند:

### راه ۱ — ساده‌ترین: لینک QR
```bash
# از gen-links.py یک کانفیگ را بردارید و QR بسازید
python3 -c "
import qrcode, sys
qrcode.make(open('out/ali.txt').readline().strip()).save('ali-qr.png')
"
```
کاربر فقط دوربین را روی QR می‌گیرد و تمام.

### راه ۲ — ساب‌اسکریپشن روی URL
فایل `ali_base64.txt` را روی یک وب‌سرور (حتی همان سرور ایران با nginx) بگذارید:
```nginx
location /sub/ali {
    alias /var/www/sub/ali_base64.txt;
    default_type text/plain;
}
```
بعد فقط لینک `https://SERVER/sub/ali` را به کاربر بدهید. هر بار که کانفیگ را عوض کردید، کاربر خودکار به‌روز می‌شود — **بدون تماس با شما**.

> 🔒 نکته امنیتی: این URL را با یک رشته‌ی تصادفی طولانی محافظت کنید، وگرنه هرکسی می‌تواند کانفیگ شما را بردارد و استفاده کند:
> ```nginx
> location /sub/$(openssl rand -hex 16) { ... }
> ```

### راه ۳ — Clash + "تست خودکار"
اگر Clash Verge Rev یا FlClash استفاده کنید، کاربر یک بار کانفیگ را وارد می‌کند و بعد فقط `Connect` می‌زند. گروه `url-test` خودش سریع‌ترین سرور را انتخاب و هنگام قطعی، خودکار عوض می‌کند. **هیچ تصمیمی از کاربر نمی‌خواهد.**

## 📊 کدام اپ را به کدام کاربر بدهید؟

| کاربر | اپ |
|---|---|
| مادر/پدر، فامیل، آشنای غیرفنی | **Hiddify** + لینک ساب‌اسکریپشن |
| دوست فنی، برنامه‌نویس | **v2rayNG** یا **NekoBox** |
| کاربری که می‌خواهد نت خودش خودکار سریع‌ترین باشد | **Clash Verge Rev / FlClash** + کانفیگ YAML |
| آیفون دارد | **Streisand** (رایگان) |
| کل خانه از یک نقطه | **mihomo روی OpenWrt** |

## 🔍 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| اپ وصل می‌شود ولی سایت باز نمی‌شود | DNS را چک کنید — در Hiddify: `Enable DNS`. در Clash: بخش `dns` در YAML هست |
| سرعت خیلی کم | تست تأخیر بزنید و کشور بهتری انتخاب کنید. اگر همه کند بودند، سرور خارجی مشکل دارد |
| کانفیگ کار نمی‌کند ولی بقیه کار می‌کنند | UUID آن کشور را در کانفیگ سرور ایران چک کنید |
| «تست خودکار» بین سرورها می‌پرد | `interval` را در YAML بالا ببرید (مثلاً ۳۰۰) و `tolerance` را زیاد کنید |
| روی Play Store نسخه‌ی مشکوکی دیدم | فقط از GitHub رسمی نصب کنید — جدول بالا را ببینید |
| باتری زیاد می‌خورد | اپ را از بهینه‌سازی باتری معاف کنید (وگرنه اندروید اتصال را می‌کشد) |

## 📦 خلاصه‌ی فایل‌های شما

```
out/
├── ali.txt              ← لینک‌های vless:// (برای v2rayNG / Hiddify)
├── ali_base64.txt       ← همان، base64 (برای «Add from clipboard»)
├── ali-clash.yaml       ← کانفیگ Clash با گروه کشور  ← new
└── ...
```

هر کدام را که کاربرتان بیشتر با آن راحت است بدهید — همه‌شان به یک سرور وصل می‌شوند.
